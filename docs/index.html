01 Что этоWhat it doesЩо це Jump List и трей — панели запуска; права решает только флаг сценария.Jump List and tray are the launch panels; elevation is per-scenario only.Jump List і трей — панелі запуску; права вирішує лише прапорець сценарію.

Список переходов и значок в трее — ваши панели запуска. Каждый сценарий превращается в задачу в Jump List на панели задач Windows и в пункт меню значка в системном трее — клик по любому из них запускает сценарий. Приложение работает строго в одном экземпляре: повторный запуск передаёт команду уже запущенному экземпляру через именованный канал (и выводит его окно), поэтому запуск мгновенный и без второго окна.

The Jump List and the tray icon are your launch panels. Each scenario becomes a task on the Windows taskbar Jump List and an entry in the system-tray menu — activating either one launches that scenario. The app runs strictly as a single instance: a repeat launch forwards the command to the already-running instance over a named pipe (and surfaces its window), so launches are instant and never open a second window.

Список переходів і значок у треї — ваші панелі запуску. Кожен сценарій перетворюється на задачу в Jump List на панелі завдань Windows і на пункт меню значка в системному треї — активація будь-якого з них запускає сценарій. Застосунок працює суворо в одному екземплярі: повторний запуск передає команду вже запущеному екземпляру через іменований канал (і виводить його вікно), тож запуск миттєвий і без другого вікна.

Права администратора решаются только флагом «Run as Admin» сценария — одинаково при любом способе запуска, без неожиданных запросов UAC.

Elevation is decided solely by a scenario's "Run as Admin" flag — the same from every launch surface, with no surprise UAC prompts.

Права адміністратора вирішуються лише прапорцем «Run as Admin» сценарію — однаково за будь-якого способу запуску, без несподіваних запитів UAC.

03 Как пользоватьсяHow to useЯк користуватися От первого запуска до горячих клавиш — пять шагов.From first launch to keyboard shortcuts — five steps.Від першого запуску до гарячих клавіш — п'ять кроків.
  1. Запустите приложение — при первом запуске оно создаёт пример сценария «Calculator» и открывает окно настроек.
  2. Нажмите Add, выберите тип (обычное приложение/скрипт или загрузка yt-dlp), укажите имя, путь и, при необходимости, аргументы, рабочую папку и «Run as Admin».
  3. Закройте окно — приложение продолжит работать свёрнутым; сценарий появится в списке переходов и в меню значка в трее.
  4. Правый клик по значку на панели задач (или в трее) → выберите сценарий, чтобы запустить его в один клик.
  5. Прямо в окне настроек: двойной клик по строке или Enter — запуск, F2 — правка, Del — удаление; строка «Search» фильтрует список.
  1. Launch the app — on first run it seeds a sample "Calculator" scenario and opens the Settings window.
  2. Click Add, choose the type (a normal app/script or a yt-dlp download), and set the name, path and — if needed — arguments, working directory and "Run as Admin".
  3. Close the window — the app keeps running minimized; the scenario appears on the Jump List and in the tray menu.
  4. Right-click the taskbar icon (or the tray icon) → pick a scenario to launch it in one click.
  5. Right in the Settings window: double-click a row or press Enter to run, F2 to edit, Del to remove; the "Search" box filters the list.
  1. Запустіть застосунок — під час першого запуску він створює приклад сценарію «Calculator» і відкриває вікно налаштувань.
  2. Натисніть Add, оберіть тип (звичайний застосунок/скрипт або завантаження yt-dlp), вкажіть ім'я, шлях і, за потреби, аргументи, робочу теку та «Run as Admin».
  3. Закрийте вікно — застосунок продовжить працювати згорнутим; сценарій з'явиться у списку переходів і в меню значка в треї.
  4. Правий клік по значку на панелі завдань (або у треї) → оберіть сценарій, щоб запустити його в один клік.
  5. Прямо у вікні налаштувань: подвійний клік по рядку або Enter — запуск, F2 — правка, Del — видалення; поле «Search» фільтрує список.
ЗаметкаNoteПримітка

Сценарии хранятся отдельными XML-файлами в %APPDATA%\OneClickRunner\Scenarios\, а действия пишутся в %APPDATA%\OneClickRunner\activity.log. Кнопкой Import можно добавить сценарий из .xml-файла.

Scenarios are stored as individual XML files in %APPDATA%\OneClickRunner\Scenarios\, and actions are written to %APPDATA%\OneClickRunner\activity.log. Use Import to add a scenario from an .xml file.

Сценарії зберігаються окремими XML-файлами в %APPDATA%\OneClickRunner\Scenarios\, а дії пишуться до %APPDATA%\OneClickRunner\activity.log. Кнопкою Import можна додати сценарій з .xml-файлу.
