02Совместимость, хранение и ограниченияCompatibility, storage, and caveatsСумісність, зберігання й обмеження

Нужны Windows 10 или 11 и .NET 8. Для PowerShell, Python и VBScript требуется соответствующий интерпретатор. Сценарии хранятся отдельными XML-файлами в %APPDATA%\OneClickRunner\Scenarios\; журнал — %APPDATA%\OneClickRunner\activity.log.

Windows 10 or 11 and .NET 8 are required. PowerShell, Python, and VBScript need their matching interpreter. Scenarios are separate XML files in %APPDATA%\OneClickRunner\Scenarios\; the log is %APPDATA%\OneClickRunner\activity.log.

Потрібні Windows 10 або 11 і .NET 8. Для PowerShell, Python і VBScript потрібен відповідний інтерпретатор. Сценарії — окремі XML-файли у %APPDATA%\OneClickRunner\Scenarios\; журнал — %APPDATA%\OneClickRunner\activity.log.

ВажноImportantВажливо

Сценарий запускает указанный вами файл. Повышение прав вызывает запрос UAC; удаление сценария удаляет его XML-файл. Проверьте путь и действие скрипта перед запуском.

A scenario runs the file you specify. Elevation triggers UAC; removing a scenario removes its XML file. Check the path and the script’s action before running it.

Сценарій запускає файл, який ви вказали. Підвищення прав викликає UAC; видалення сценарію видаляє його XML-файл. Перевірте шлях і дію скрипта перед запуском.
