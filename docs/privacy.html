One Click Runner - локальный лаунчер. Он не делает сетевых запросов сам по себе: ни телеметрии, ни аналитики, ни проверки обновлений, ни отправки отчётов о сбоях. Ниже - что именно он пишет на диск, к каким настройкам Windows обращается и как всё это удалить. One Click Runner is a local launcher. It makes no network calls of its own: no telemetry, no analytics, no update check, no crash reporting. Below is exactly what it writes to disk, which Windows settings it touches, and how to remove all of it. One Click Runner - локальний лаунчер. Він не робить мережевих запитів сам по собі: ні телеметрії, ні аналітики, ні перевірки оновлень, ні надсилання звітів про збої. Нижче - що саме він пише на диск, до яких налаштувань Windows звертається і як усе це видалити.

01 Что хранится на вашем компьютереWhat is stored on your computerЩо зберігається на вашому комп'ютері Три обычных файла в вашем профиле пользователя. Без базы данных и облачной синхронизации.Three plain files inside your own user profile. No database, no cloud sync.Три звичайні файли у вашому профілі користувача. Без бази даних і хмарної синхронізації.
  • %APPDATA%\OneClickRunner\Scenarios\ - по одному XML-файлу на сценарий. В нём то, что вы ввели в окне настроек: имя, путь, аргументы, рабочая папка, флаг «Run as Administrator», порядок в списке, тип сценария и - для yt-dlp - папка загрузки и дополнительные опции.
  • %APPDATA%\OneClickRunner\activity.log - текстовый журнал с отметками времени: какой сценарий запущен, собранная командная строка вместе с аргументами, ссылка, введённая для yt-dlp, путь файла при экспорте и тексты ошибок. Приложение только дописывает журнал и не подрезает его.
  • %APPDATA%\OneClickRunner\.initialized - метка первого запуска (одна отметка времени), чтобы пример сценария «Calculator» не появлялся снова.
  • %APPDATA%\OneClickRunner\Scenarios\ - one XML file per scenario. It holds what you typed into the Settings window: name, path, arguments, working folder, the "Run as Administrator" flag, the position in the list, the scenario type, and - for yt-dlp - the download folder and extra options.
  • %APPDATA%\OneClickRunner\activity.log - a timestamped text log: which scenario was launched, the assembled command line including its arguments, the link you typed for a yt-dlp scenario, the destination path of an export, and error text. The app only appends to it and never trims it.
  • %APPDATA%\OneClickRunner\.initialized - a first-run marker (a single timestamp) so the sample "Calculator" scenario is not seeded again.
  • %APPDATA%\OneClickRunner\Scenarios\ - по одному XML-файлу на сценарій. У ньому те, що ви ввели у вікні налаштувань: ім'я, шлях, аргументи, робоча тека, прапорець «Run as Administrator», порядок у списку, тип сценарію і - для yt-dlp - тека завантаження та додаткові опції.
  • %APPDATA%\OneClickRunner\activity.log - текстовий журнал з відмітками часу: який сценарій запущено, зібраний командний рядок разом з аргументами, посилання, введене для yt-dlp, шлях файлу під час експорту та тексти помилок. Застосунок лише дописує журнал і не підрізає його.
  • %APPDATA%\OneClickRunner\.initialized - позначка першого запуску (одна відмітка часу), щоб приклад сценарію «Calculator» не з'являвся знову.
ВажноImportantВажливо

Всё это - обычные файлы в вашем профиле пользователя, доступные вам и любому, кто работает под вашей учётной записью. Приложение их не шифрует и никуда не копирует.

These are plain files inside your own user profile, readable by you and by anyone working under your account. The app does not encrypt them and does not copy them anywhere.

Усе це - звичайні файли у вашому профілі користувача, доступні вам і будь-кому, хто працює під вашим обліковим записом. Застосунок їх не шифрує і нікуди не копіює.

02 Что уходит с компьютераWhat leaves your computerЩо йде з комп'ютера Из самого приложения - ничего. Сеть используют программы, которые вы запускаете.From the app itself, nothing. The network is used by the programs you launch.Із самого застосунку - нічого. Мережу використовують програми, які ви запускаєте.
  • Нет телеметрии и аналитики. Приложение не собирает статистику использования и не отправляет её ни на какой сервер.
  • Нет проверки обновлений. Версия читается из атрибута собственной сборки; приложение никуда не обращается, чтобы узнать, вышла ли новая.
  • Нет отчётов о сбоях. Ошибки попадают только в локальный activity.log.
  • Нет учётных записей. Регистрация, вход и синхронизация отсутствуют как функция.
  • Именованный канал - локальный. Второй запуск передаёт команду уже работающей копии через именованный канал Windows на этом же компьютере. Он не выходит за пределы машины.
  • No telemetry, no analytics. The app collects no usage statistics and sends none to any server.
  • No update check. The version is read from the app's own build attribute; nothing is contacted to find out whether a newer one exists.
  • No crash reporting. Errors go only into the local activity.log.
  • No accounts. There is no sign-up, sign-in, or sync feature at all.
  • The named pipe is local. A second launch hands its command to the already-running copy through a Windows named pipe on this same machine. It never leaves the computer.
  • Немає телеметрії та аналітики. Застосунок не збирає статистику використання і не надсилає її на жоден сервер.
  • Немає перевірки оновлень. Версія читається з атрибута власної збірки; застосунок нікуди не звертається, щоб дізнатися про новішу.
  • Немає звітів про збої. Помилки потрапляють лише до локального activity.log.
  • Немає облікових записів. Реєстрації, входу та синхронізації немає як функції.
  • Іменований канал - локальний. Другий запуск передає команду вже запущеній копії через іменований канал Windows на цьому ж комп'ютері. Він не виходить за межі машини.
Что делает сетьWhat does use the networkЩо використовує мережу

Сценарий запускает выбранную вами программу, и её поведение в сети - её собственное. Сценарий с адресом http(s) открывает ваш браузер. Сценарий yt-dlp запускает установленный вами yt-dlp в видимом окне консоли, и уже он скачивает по введённой ссылке. One Click Runner не скачивает ничего сам и не поставляет yt-dlp в комплекте.

A scenario starts a program you chose, and that program's network behaviour is its own. A scenario pointing at an http(s) address opens your browser. A yt-dlp scenario starts the yt-dlp you installed, in a visible console window, and that program does the downloading from the link you typed. One Click Runner downloads nothing itself and does not bundle yt-dlp.

Сценарій запускає обрану вами програму, і її поведінка в мережі - її власна. Сценарій з адресою http(s) відкриває ваш браузер. Сценарій yt-dlp запускає встановлений вами yt-dlp у видимому вікні консолі, і вже він завантажує за введеним посиланням. One Click Runner нічого не завантажує сам і не постачає yt-dlp у комплекті.

03 Пароли и ключи: чего не стоит вводитьPasswords and keys: what not to type inПаролі та ключі: чого не варто вводити Хранилища секретов нет. Поле Arguments сохраняется как есть - и попадает в журнал.There is no secret store. The Arguments field is saved verbatim, and it reaches the log.Сховища секретів немає. Поле Arguments зберігається як є - і потрапляє до журналу.

Приложение не запрашивает и не хранит пароли, токены и ключи: у него нет учётных записей и нет собственного хранилища секретов. Ничего не шифруется, потому что нет данных, которые приложение считало бы секретом.

The app never asks for and never stores a password, token, or key: it has no accounts and no secret store of its own. Nothing is encrypted, because there is nothing the app treats as a secret.

Застосунок не запитує і не зберігає паролі, токени та ключі: у нього немає облікових записів і немає власного сховища секретів. Нічого не шифрується, бо немає даних, які застосунок вважав би секретом.

ВниманиеCautionУвага

Всё, что вы напишете в поле Arguments, сохраняется в XML-файле сценария открытым текстом и при каждом запуске дописывается в activity.log. Пароль или API-ключ, введённый туда, окажется в двух обычных файлах. Передавайте секреты через переменные окружения или менеджер учётных данных внутри собственного скрипта, а не через это поле. То же касается ссылки для yt-dlp: она пишется в журнал.

Anything you put in the Arguments field is saved to the scenario's XML file in plain text and appended to activity.log on every launch. A password or API key typed there ends up in two plain files. Pass secrets through environment variables or a credential helper inside your own script instead of this field. The same applies to a yt-dlp link: it is written to the log.

Усе, що ви напишете в полі Arguments, зберігається у XML-файлі сценарію відкритим текстом і під час кожного запуску дописується до activity.log. Пароль або API-ключ, введений туди, опиниться у двох звичайних файлах. Передавайте секрети через змінні середовища або менеджер облікових даних усередині власного скрипта, а не через це поле. Те саме стосується посилання для yt-dlp: воно пишеться в журнал.

04 К каким настройкам Windows обращается приложениеWhich Windows settings the app touchesДо яких налаштувань Windows звертається застосунок Одно значение в реестре по вашему выбору, одно читается, плюс список переходов.One registry value you opt into, one it reads, plus the Jump List.Одне значення в реєстрі за вашим вибором, одне читається, плюс список переходів.
  • Автозапуск (запись). Галочка «Start OneClickRunner when Windows starts» создаёт значение OneClickRunner в HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run; в нём только путь к исполняемому файлу. Снятие галочки это значение удаляет. Без вашего действия оно не появляется.
  • Тема оформления (чтение). Приложение читает AppsUseLightTheme в HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize, чтобы следовать светлой или тёмной теме Windows. Только чтение.
  • Список переходов и меню трея. Имена сценариев передаются Windows, чтобы нарисовать список переходов на панели задач. Windows хранит свою копию этого списка - иначе он не работал бы, когда приложение закрыто.
  • Диалоги файлов. Импорт и экспорт открывают стандартные диалоги Windows; приложение читает и пишет только тот файл, который вы в них выбрали.
  • Autostart (write). The "Start OneClickRunner when Windows starts" checkbox creates a OneClickRunner value under HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run, holding only the path to the executable. Clearing the checkbox removes it. It never appears without your action.
  • Theme (read). The app reads AppsUseLightTheme under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize so it can follow the Windows light or dark setting. Read only.
  • Jump List and tray menu. Scenario names are handed to Windows so it can draw the taskbar Jump List. Windows keeps its own copy of that list - otherwise it could not work while the app is closed.
  • File dialogs. Import and export open the standard Windows dialogs; the app reads and writes only the file you picked in them.
  • Автозапуск (запис). Позначка «Start OneClickRunner when Windows starts» створює значення OneClickRunner у HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run; у ньому лише шлях до виконуваного файлу. Знята позначка це значення видаляє. Без вашої дії воно не з'являється.
  • Тема оформлення (читання). Застосунок читає AppsUseLightTheme у HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize, щоб дотримуватись світлої або темної теми Windows. Лише читання.
  • Список переходів і меню трея. Імена сценаріїв передаються Windows, щоб намалювати список переходів на панелі завдань. Windows зберігає свою копію цього списку - інакше він не працював би, коли застосунок закрито.
  • Діалоги файлів. Імпорт і експорт відкривають стандартні діалоги Windows; застосунок читає й пише лише той файл, який ви в них обрали.
05 Права администратораAdministrator rightsПрава адміністратора Само приложение работает с обычными правами. Повышение - только для отмеченного сценария.The app itself runs with your normal rights. Elevation happens only for a scenario you ticked.Сам застосунок працює зі звичайними правами. Підвищення - лише для позначеного сценарію.

One Click Runner запускается с вашими обычными правами пользователя и не просит повышения для себя. Отдельный сценарий стартует с повышенными правами только тогда, когда именно у него включена галочка Run as Administrator; решение о выдаче прав принимает Windows и показывает вам запрос UAC. Отказ от запроса просто отменяет запуск.

One Click Runner starts with your normal user rights and never asks for elevation for itself. An individual scenario starts elevated only when that scenario's Run as Administrator checkbox is ticked; Windows makes the decision and shows you the UAC prompt. Declining the prompt simply cancels the launch.

One Click Runner запускається з вашими звичайними правами користувача і не просить підвищення для себе. Окремий сценарій стартує з підвищеними правами лише тоді, коли саме в нього увімкнено позначку Run as Administrator; рішення ухвалює Windows і показує вам запит UAC. Відмова від запиту просто скасовує запуск.

Правило одинаково для всех способов запуска - из списка переходов, из меню в трее, из окна настроек и из командной строки.

The rule is the same for every launch surface - the Jump List, the tray menu, the Settings window, and the command line.

Правило однакове для всіх способів запуску - зі списку переходів, з меню в треї, з вікна налаштувань і з командного рядка.

06 Как удалить всё, что записало приложениеHow to remove everything the app wroteЯк видалити все, що записав застосунок Одна папка и одно значение в реестре. Ничего не остаётся вне вашего профиля.One folder and one registry value. Nothing survives outside your profile.Одна тека й одне значення в реєстрі. Нічого не залишається поза вашим профілем.
  1. Снимите галочку «Start OneClickRunner when Windows starts» в настройках - это удалит значение в реестре. Если приложение уже удалено, удалите значение OneClickRunner в ключе HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run вручную.
  2. Удалите папку %APPDATA%\OneClickRunner - вместе с ней уйдут все сценарии, журнал и метка первого запуска.
  3. Удалите распакованную папку приложения. Установщика нет, программа поставляется переносимым архивом.
  1. Clear the "Start OneClickRunner when Windows starts" checkbox in Settings - that removes the registry value. If the app is already gone, delete the OneClickRunner value under the HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run key by hand.
  2. Delete the %APPDATA%\OneClickRunner folder - every scenario, the log, and the first-run marker go with it.
  3. Delete the unpacked app folder. There is no installer; the program ships as a portable archive.
  1. Зніміть позначку «Start OneClickRunner when Windows starts» у налаштуваннях - це видалить значення в реєстрі. Якщо застосунок уже видалено, видаліть значення OneClickRunner у ключі HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run вручну.
  2. Видаліть теку %APPDATA%\OneClickRunner - разом з нею зникнуть усі сценарії, журнал і позначка першого запуску.
  3. Видаліть розпаковану теку застосунку. Інсталятора немає, програма постачається переносним архівом.
