Настройка и использованиеSetup & usageНалаштування та використання

Установите One Click Runner, создайте «сценарий» для любого приложения или скрипта — и запускайте его в один клик из списка переходов на панели задач. Install One Click Runner, create a "scenario" for any app or script, and launch it in one click from the taskbar Jump List. Встановіть One Click Runner, створіть «сценарій» для будь-якого застосунку чи скрипта — і запускайте його в один клік зі списку переходів на панелі завдань.

04 Запуск из списка переходовLaunch from the Jump ListЗапуск зі списку переходів Правый клик по значку — мгновенно, в одном экземпляре.Right-click the icon and pick a scenario — instant, single instance.Правий клік по значку — миттєво, в одному екземплярі.
  1. Закройте окно настроек — приложение продолжит работать свёрнутым.
  2. Правый клик по значку One Click Runner на панели задач.
  3. В списке переходов выберите свой сценарий — он запустится сразу.
  1. Close the Settings window — the app keeps running minimized.
  2. Right-click the One Click Runner icon on the taskbar.
  3. Pick your scenario from the Jump List — it launches immediately.
  1. Закрийте вікно налаштувань — застосунок продовжить працювати згорнутим.
  2. Правий клік по значку One Click Runner на панелі завдань.
  3. У списку переходів оберіть свій сценарій — він запуститься одразу.

Приложение работает строго в одном экземпляре: клик по задаче передаёт команду уже запущенному экземпляру через именованный канал, поэтому второе окно не открывается — повторный запуск просто выводит уже открытое окно. Сценарий можно запустить и прямо из окна настроек кнопкой Run (или двойным кликом по строке).

The app runs strictly as a single instance: clicking a task forwards the command to the already-running instance over a named pipe, so no second window opens — a repeat launch simply surfaces the window that is already open. You can also launch a scenario straight from the Settings window with the Run button (or by double-clicking the row).

Застосунок працює суворо в одному екземплярі: клік по задачі передає команду вже запущеному екземпляру через іменований канал, тож друге вікно не відкривається — повторний запуск просто виводить уже відкрите вікно. Сценарій можна запустити й прямо з вікна налаштувань кнопкою Run (або подвійним кліком по рядку).

Ещё способыMore waysЩе способи

Значок в трее: двойной клик открывает настройки, правый клик показывает те же сценарии плюс Настройки и Выход. В списке: правый клик по строке — контекстное меню (Run, Edit, Clone, Export, Remove); горячие клавиши — Enter (запуск), F2 (правка), Del (удаление).

Tray icon: double-click opens Settings, right-click shows the same scenarios plus Settings and Exit. In the list: right-click a row for a context menu (Run, Edit, Clone, Export, Remove); keyboard — Enter (run), F2 (edit), Del (remove).

Значок у треї: подвійний клік відкриває налаштування, правий клік показує ті самі сценарії плюс Налаштування та Вихід. У списку: правий клік по рядку — контекстне меню (Run, Edit, Clone, Export, Remove); гарячі клавіші — Enter (запуск), F2 (правка), Del (видалення).

Где лежат файлыWhere files liveДе лежать файли

Каждый сценарий — отдельный XML-файл в %APPDATA%\OneClickRunner\Scenarios\. Действия пишутся в %APPDATA%\OneClickRunner\activity.log — это первое место, куда стоит заглянуть, если сценарий не запускается.

Each scenario is a standalone XML file in %APPDATA%\OneClickRunner\Scenarios\. Actions are logged to %APPDATA%\OneClickRunner\activity.log — the first place to look if a scenario won't launch.

Кожен сценарій — окремий XML-файл у %APPDATA%\OneClickRunner\Scenarios\. Дії пишуться до %APPDATA%\OneClickRunner\activity.log — це перше місце, куди варто заглянути, якщо сценарій не запускається.
