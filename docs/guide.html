Настройка и использованиеSetup & usageНалаштування та використання

Установите OneClickRunner, создайте «сценарий» для любого приложения или скрипта — и запускайте его в один клик из списка переходов на панели задач. Install OneClickRunner, create a "scenario" for any app or script, and launch it in one click from the taskbar Jump List. Встановіть OneClickRunner, створіть «сценарій» для будь-якого застосунку чи скрипта — і запускайте його в один клік зі списку переходів на панелі завдань.

01 УстановкаInstallВстановлення

  • Готовый релиз — скачайте со страницы релизов, распакуйте и запустите OneClickRunner.exe.
  • Сборка из исходников — нужен .NET 8 SDK (команды ниже).
  • Prebuilt release — download from the Releases page, extract and run OneClickRunner.exe.
  • Build from source — needs the .NET 8 SDK (commands below).
  • Готовий реліз — завантажте зі сторінки релізів, розпакуйте та запустіть OneClickRunner.exe.
  • Збірка з вихідників — потрібен .NET 8 SDK (команди нижче).

СоветTipПорада

Для PowerShell / Python / VBScript на машине должен быть установлен соответствующий интерпретатор (powershell, python, wscript). Аргументы и рабочую папку задавайте в тех же полях сценария.

PowerShell / Python / VBScript scenarios need the matching interpreter installed (powershell, python, wscript). Set arguments and the working directory in the same scenario fields.

Для PowerShell / Python / VBScript на машині має бути встановлений відповідний інтерпретатор (powershell, python, wscript). Аргументи та робочу теку задавайте в тих самих полях сценарію.

04 Запуск из списка переходовLaunch from the Jump ListЗапуск зі списку переходів

  1. Закройте окно настроек — приложение продолжит работать свёрнутым.
  2. Правый клик по значку OneClickRunner на панели задач.
  3. В списке переходов выберите свой сценарий — он запустится сразу.
  1. Close the Settings window — the app keeps running minimized.
  2. Right-click the OneClickRunner icon on the taskbar.
  3. Pick your scenario from the Jump List — it launches immediately.
  1. Закрийте вікно налаштувань — застосунок продовжить працювати згорнутим.
  2. Правий клік по значку OneClickRunner на панелі завдань.
  3. У списку переходів оберіть свій сценарій — він запуститься одразу.

Приложение работает в одном экземпляре: клик по задаче передаёт команду уже запущенному экземпляру через именованный канал, поэтому второе окно не открывается. Сценарий можно запустить и прямо из окна настроек кнопкой Run (или двойным кликом по строке).

The app runs as a single instance: clicking a task forwards the command to the already-running instance over a named pipe, so no second window opens. You can also launch a scenario straight from the Settings window with the Run button (or by double-clicking the row).

Застосунок працює в одному екземплярі: клік по задачі передає команду вже запущеному екземпляру через іменований канал, тож друге вікно не відкривається. Сценарій можна запустити й прямо з вікна налаштувань кнопкою Run (або подвійним кліком по рядку).

05 Управление и хранениеManage & storageКерування та зберігання

  • Add / Edit / Clone / Remove — создать, изменить, клонировать или удалить сценарий.
  • Import — добавить сценарий из .xml-файла (ему назначается новый идентификатор).
  • Autostart — «Start OneClickRunner when Windows starts» запускает приложение свёрнутым вместе с Windows.
  • Add / Edit / Clone / Remove — create, modify, duplicate or delete a scenario.
  • Import — add a scenario from an .xml file (it gets a fresh id).
  • Autostart — "Start OneClickRunner when Windows starts" launches the app minimized with Windows.
  • Add / Edit / Clone / Remove — створити, змінити, клонувати чи видалити сценарій.
  • Import — додати сценарій з .xml-файлу (йому призначається новий ідентифікатор).
  • Autostart — «Start OneClickRunner when Windows starts» запускає застосунок згорнутим разом із Windows.
Где лежат файлыWhere files liveДе лежать файли

Каждый сценарий — отдельный XML-файл в %APPDATA%\OneClickRunner\Scenarios\. Действия пишутся в %APPDATA%\OneClickRunner\activity.log — это первое место, куда стоит заглянуть, если сценарий не запускается.

Each scenario is a standalone XML file in %APPDATA%\OneClickRunner\Scenarios\. Actions are logged to %APPDATA%\OneClickRunner\activity.log — the first place to look if a scenario won't launch.

Кожен сценарій — окремий XML-файл у %APPDATA%\OneClickRunner\Scenarios\. Дії пишуться до %APPDATA%\OneClickRunner\activity.log — це перше місце, куди варто заглянути, якщо сценарій не запускається.
